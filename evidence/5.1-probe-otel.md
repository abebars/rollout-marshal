## How to read this file

This uses task 2.7's conventions:
- **Times** are 2026-11-27, UTC. The AWS CLI prints AWS timestamps in local time (UTC-05:00) or
  as epoch milliseconds, and the text converts them.
- **Each command is marked read or write.** Its line gives the UTC time, the exact command, its
  exit code and its output. Output is raw unless the block says quoted.
- **Where each time comes from:**
  - **start:** `date -u` printed it just before the command.
  - **end:** `date -u` printed it just after.
  - **Millisecond times** are printed by the wrapper as the command starts.
- **Local** marks a command that reads files on this machine and makes no AWS call.
- **The prefix.** `...` stands for
  `env -u AWS_ACCESS_KEY_ID -u AWS_SECRET_ACCESS_KEY -u AWS_SESSION_TOKEN AWS_PROFILE=abisb_IsbAdminsPS-818928662830 AWS_REGION=us-east-1`.
  It is the human's SSO profile, in account `818928662830`.
- **The lead's record.** Where a fact is the lead's, the text says so.

## 2. The fix (`1cc3cb0`)

- **`agent/runtime/rm_agent/tools/untraced.py`** (new): `suppress_instrumentation`, imported
  guarded. Where opentelemetry is not installed, it falls back to `contextlib.nullcontext`. Its
  docstring says why.
- **`probe._invoke`** runs its `client.invoke` inside `suppress_instrumentation()`, with a
  comment.
- **`flagsmith.LambdaAdmin.call`** does the same. It is the only other direct Lambda invoke with
  a JSON payload in `agent/runtime`; a grep for `.invoke(` found these two. It is 2.2's laptop
  path, and `main.py` uses `GatewayAdmin`.
- **`agent/tests/test_untraced_invokes.py`**, six tests:
  - **Instrumentation is off at each invoke.** The real `is_instrumentation_enabled()` reads
    false: for `probe._invoke`, in each of `probe_cheaper`'s five threads, and for
    `LambdaAdmin.call`. It reads true again afterwards.
  - **The guarded import works.** Without opentelemetry, it falls back to
    `contextlib.nullcontext`.
  - **The payload arrives exactly as written.** Two tests instrument botocore with
    `BotocoreInstrumentor` and stub a real Lambda client, so `Payload` must equal
    `json.dumps(...)` exactly. They skip where `opentelemetry-instrumentation-botocore` is
    missing, which is the case in the root environment.

"""Workstream A scratch (task 5.1): the AWS distro's patched botocore path, with and without
the probe's suppression. Runs in agent/runtime's dependency set; no AWS call (Stubber)."""

import io
import json
import sys

sys.path[:0] = ["agent/runtime", "."]

import boto3  # noqa: E402
from amazon.opentelemetry.distro.patches._botocore_patches import (  # noqa: E402
    _apply_botocore_instrumentation_patches,
)
from botocore.response import StreamingBody  # noqa: E402
from botocore.stub import Stubber  # noqa: E402
from opentelemetry.instrumentation.botocore import BotocoreInstrumentor  # noqa: E402
from rm_agent.tools import probe  # noqa: E402

from contracts import names  # noqa: E402

REPLY = json.dumps({"answer": "ok", "input_tokens": 1, "output_tokens": 1,
                    "model_id": names.MODEL_CHEAPER}).encode()


def client_and_stub():
    client = boto3.Session(aws_access_key_id="x", aws_secret_access_key="x",
                           region_name="us-east-1").client("lambda")
    stub = Stubber(client)
    seen = {}

    def record(params, **_):
        seen["Payload"] = params.get("Payload")

    client.meta.events.register("before-parameter-build.lambda.Invoke", record)
    stub.add_response("invoke", {"StatusCode": 200,
                                 "Payload": StreamingBody(io.BytesIO(REPLY), len(REPLY))})
    return client, stub, seen


_apply_botocore_instrumentation_patches()
print("distro patch applied:", BotocoreInstrumentor._patched_api_call.__qualname__)
BotocoreInstrumentor().instrument()
try:
    client, stub, seen = client_and_stub()
    with stub:
        client.invoke(FunctionName=names.ANSWER_CHEAPER_FUNCTION,
                      InvocationType="RequestResponse", Payload=json.dumps(probe._REQUEST))
    print("direct invoke, no suppression:", seen["Payload"])
    client, stub, seen = client_and_stub()
    with stub:
        _, problem = probe._invoke(client)
    print("probe._invoke with the fix:   ", seen["Payload"], "| problem:", problem)
finally:
    BotocoreInstrumentor().uninstrument()
