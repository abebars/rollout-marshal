# Evidence: task 3.6, deployed smoke

Prepared on 2026-11-27, before the apply. Nothing below has run yet. The run starts only
when the lead says the app and FIS modules are applied; the results go under each step.

## The run sheet

Every command runs from the repository root, in a shell signed in to 818928662830:

```
unset AWS_ACCESS_KEY_ID AWS_SECRET_ACCESS_KEY AWS_SESSION_TOKEN
export AWS_PROFILE=<the human's profile in 818928662830>
```

1. **Account.** `aws sts get-caller-identity --query Account --output text` must print
   `818928662830`.
2. **Flagsmith usage before.** `uv run python evidence/3.6-scripts/smoke_reads.py usage`
   gives the organisation's request count, against the stop line of 35,000.
3. **Permanent features.** `uv run python scripts/bootstrap_flagsmith.py` creates
   `assistant_cheaper_enabled` and `assistant_default_model`, or finds and checks them.
4. **The URL, never printed.** `ASK_URL` is read into the shell without echoing it, in one
   of two ways (the lead's review):
   - `terraform output -raw ask_url`, in the lead's checkout;
   - read-only, with no state: `rm-api`'s `ApiEndpoint` from `aws apigatewayv2 get-apis`,
     plus `/ask`.

   The repo is public: the URL stays out of this file.
5. **One signed request first.** EMF under JSON at INFO is documented but not yet seen on a
   deployed function (PR #27's review), so check it before the load:
   - `RUN_ID=rsmoke$(date -u +%H%M)`, and note `date -u` as `PROBE_AT`;
   - `uv run python scripts/load.py --run-id $RUN_ID --users 1 --questions 1 --url "$ASK_URL"`;
   - after about 2 minutes, `uv run python evidence/3.6-scripts/smoke_reads.py seen --since $PROBE_AT`
     must print `"seen": true` (it exits 1 otherwise).

   With no pointer yet, the router serves the default model: no exposure, no event and no
   judge. So this one answer is not in `AnswerCostMicroUsd`, about 11,400 micro-USD at
   Fable's price. It counts toward the answers sent. If nothing is seen, stop: the load
   would produce no metrics.
6. **Seed.** `uv run python scripts/seed_experiment.py $RUN_ID` creates and starts the
   experiment, then writes the pointer. Record the experiment ID it prints.
7. **Load.** Note `date -u` before and after:
   `uv run python scripts/load.py --run-id $RUN_ID --users 150 --questions 2 --url "$ASK_URL"`.
   Record its sent, ok and failed counts: 300 answers, 301 with the probe.
8. **Wait** about 3 minutes. In task 1.2, all events were in about 2 min 15 s after the
   last was sent (design.md section 4).
9. **Baseline latency.**
   `uv run python evidence/3.6-scripts/smoke_reads.py latency --start <load start> --end <load end>`
   gives:
   - `AnswerLatencyMs` p95 for exactly `Variant=cheaper` over the window, as one period;
   - each variant's sample count, both of which must be non-zero;
   - 4.1's threshold from it: p95 + 5000 ms, rounded up to the next 1000, flagged when
     the p95 is past 8000 ms.
10. **Cost check.**
    `uv run python evidence/3.6-scripts/smoke_reads.py cost --answers-sent 301 --expected-failures <F>`
    gives:
    - each variant's Sum and SampleCount of `AnswerCostMicroUsd` since
      2026-11-26T02:30:00Z, period 3600, every datapoint added;
    - the projection: spent, plus (5,100 − 301 + 300 × F) answers at the higher mean;
    - whether the lead must ask the human: past 60,000,000, or answers past 7,500.

    The projection goes to the lead as soon as this read is in.
11. **Results.**
    `uv run python evidence/3.6-scripts/smoke_reads.py results <experiment ID> --refresh`
    asks for one refresh. It waits until the read is current by design.md section 7's
    three conditions, then writes `evidence/3.6-results.json`: the raw reply beside the
    experiment read's `experiment_metrics`. It prints:
    - each arm's identities and each metric's `n`, which settles whether `n` counts
      identities or events;
    - the means;
    - the cheaper arm's lift, interval and chance to win.
12. **Flagsmith usage after.** Run `smoke_reads.py usage` again, at least 30 minutes after
    the load: the read lags by more than 25 minutes (design.md section 13). The billable
    requests Flagsmith's billing docs list are `/flags`, `/identities` and
    `/environment-document`. The smoke makes 300 identity requests, plus the probe's one
    environment-flags request. Any rise beyond those 301 would mean events count, which is
    what tasks.md 3.6 asks.
13. **The human ends the experiment** in the Flagsmith dashboard.
14. **Reset.** `uv run python scripts/reset.py` clears the pointer and puts the flags and
    the tick back.
