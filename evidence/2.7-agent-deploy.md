## How to read this file

- **Times** are 2026-11-27, UTC. The AWS CLI prints AWS timestamps in local time (UTC-05:00);
  the text converts them.
- **Each command is marked read or write.** Its line gives the UTC time, the exact command, its
  exit code and its output.
  - Output is raw unless the block says quoted.
  - The credential provider's secret name is written
    `bedrock-agentcore-identity!default/apikey/rm-flagsmith-api-key-<suffix>`.
- **Where each time comes from:**
  - **start:** `date -u` printed it just before the command.
  - **end:** `date -u` printed it just after.
  - **CloudTrail:** the event time CloudTrail recorded for the call. A lookup block shows it.
  - **Millisecond times** are re-reads, printed by the wrapper as the command starts.
- **The prefix.** `...` stands for
  `env -u AWS_ACCESS_KEY_ID -u AWS_SECRET_ACCESS_KEY -u AWS_SESSION_TOKEN AWS_PROFILE=abisb_IsbAdminsPS-818928662830 AWS_REGION=us-east-1`.
  It is the human's SSO profile, with the stale environment credentials removed.
- **Re-reads.** Some reads during the live half printed no time. They ran again at
  09:34–09:37Z, after it. Nothing has written to what they read since. Their output matches
  the first reads, apart from the secret's suffix, now written `<suffix>`.

- **The two CloudTrail lookups** (commands 3 and 16) cannot be rerun by a goldfish: an
  organisation SCP denies `cloudtrail:LookupEvents` to `rm-review-readonly`, as it denies FIS.
  So the lead reruns them with the SSO profile and records the output, as docs/REVIEW.md has it
