## How the page shows a price

The page's Anthropic tables are not text in the HTML.
- **The placeholders.** Each price cell is a placeholder, such as
  `{priceOf!bedrockfoundationmodels/bedrockfoundationmodels!OmpgwTH7ud9PrYYiaESlRL-ViihvxakEM1AMVvXSEH8!opt}`.
  It sits inside a pricing widget's `data-pricing-markup` attribute, beside
  `data-pricing-endpoint="https://b0.p.awsstatic.com/pricing/2.0/meteredUnitMaps"`.
- **The widget's script.** The page's script, `https://b0.p.awsstatic.com/client-side-script/static/js/main.bundle.js`,
  fetches one price file for each token path `<service>/<file>`. It builds the URL as
  `${endpoint}${partition}/${service}/USD/current/${file}.json` (`partition` is empty for
  `aws`), and shows `regions[<selected region>][<key>]["price"]`. The fragments, as read
  in that script:
  - ``(t="aws"===r?"":`/${r}`,`${a}${t}/${n}/${"aws-cn"===r?"CNY":"aws-eusc"===r?"EUR":"USD"}/current/${o}.json`)``
  - `let e=r.regions[n][t.key]` … `case"priceOf":{let n=e[t.attributes.at(0)||"price"]`
- **The tables.** Each table has a region selector (`{regionSelector}`). Two are under
  Anthropic > On-Demand and Batch pricing:
  - widget 34, "Geo and In-region Cross-region Inference", the `us.` profiles' table;
  - widget 33, "Global Cross-region Inference", the `global.` profiles' table.

I resolved the cells the way that script does, for "US East (N. Virginia)".

`evidence/3.3-scripts/resolve_prices.py` is the script exactly as it ran. It:
- finds the widget by its index and checks the widget's title;
- takes each row's first two price cells, input and output;
- looks each placeholder's key up in its price file under the region.

The two `cHVib…` files are AWS Marketplace offers' price files: Haiku 5.5's, one for each
table. Fable 5.1 and Sonnet 5 read `bedrockfoundationmodels.json`. Both answer the same
`regions` map.

  the judge's prompts are far shorter. Nor are the batch and cache columns used.

reading of the rendered table. To check them by eye: open the page and choose Anthropic,
then On-Demand and Batch pricing, then "Geo and In-region Cross-region Inference". Then
select US East (N. Virginia).
